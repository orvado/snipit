# Taste

## Workflow

- Prefers to develop major rewrites/porting work on a separate git branch so the original working build stays untouched and unaffected. Confidence: 0.9
- When converting or porting an app to a new stack/platform, expects full feature parity with the original ("same feature set as before") rather than a reduced scope. Confidence: 0.8
- Values apps supporting multiple desktop platforms (macOS and Windows) instead of remaining single-OS. Confidence: 0.6
